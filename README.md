# JTGeats

This project is a frontend implementation of the JTGeats food ordering website.

The goal was to build a responsive and interactive user interface while closely following the provided design. The website includes food listings, a popular items carousel, quantity selection, cart interactions, a request dish modal, a video section, and a contact form.

## Tech Stack

- HTML
- CSS
- JavaScript

## Features

- Responsive layout for desktop, tablet, and mobile devices
- Food item listing section
- Popular items carousel
- Quantity selector and cart interactions
- Request Dish modal
- Video section with playback controls
- Contact form validation
- Keyboard accessible interactions
